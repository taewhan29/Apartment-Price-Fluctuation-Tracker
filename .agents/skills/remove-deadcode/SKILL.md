# REMOVE-DEADCODE — 미사용 코드 탐지 및 정리 스킬

## 개요
프로젝트 내에서 참조되지 않거나 호출되지 않는 도달 불가능한 코드(Unreachable code), 사용되지 않는 변수/임포트/함수/파일을 안전하게 추적하여 정리합니다.

## 실행 규칙 및 안전 지침

1. **참조 탐지 (Reference Check)**
   - 코드 수정을 진행하기 전 `grep_search` 등을 사용하여 해당 심볼이 외부 모듈이나 동적 로딩, 테스트 코드에서 참조되는지 확실히 확인합니다.

2. **안전한 제거 방식**
   - 불필요한 `import` 구문 제거
   - 호출되지 않는 내부 헬퍼 함수/클래스 제거
   - 접근 불가능한 조건문 분기 정리

3. **테스트 및 검증**
   - 제거 후 기존 기능 동작이나 빌드/구동에 영향을 주지 않는지 검증합니다.
