# HYPERPLAN — 교차 비평 기반 고품질 설계/계획 스킬

## 개요
계획 수립 단계에서 단일 시각의 맹점을 방지하기 위해 4가지 핵심 검증 렌즈(실용주의 관점, 통합 예외 관점, 근거 증명 관점, 아키텍처 구조 관점)로 수립 중인 계획을 무자비하게 검증하고 승인된 고품질 실행 계획만 도출합니다.

## 4대 비평 렌즈

### 1. 실용주의 검증 (Pragmatist Skeptic)
- 과잉 엔지니어링, 조기 추상화, 필요 이상의 복잡성을 공격합니다.
- 질문: "오늘 당장 가장 단순하게 동작하는 방법은 무엇인가?", "이 추상화가 당장 제공하는 가치는 무엇인가?"

### 2. 예외 및 통합 검증 (Integration Validator)
- 모듈 간 결합도, 예외 처리 누락, 사이드 이펙트, 경계 조건(Edge case)을 검증합니다.
- 질문: "이 모듈이 실패하면 영향을 받는 주변 모듈은 무엇인가?", "놓친 예외 처리 조건은 없는가?"

### 3. 근거 증명 검증 (Evidence Researcher)
- 추측성 판단("아마 이렇게 동작할 것이다")을 배제하고 정확한 코드/문서 근거를 요구합니다.
- 질문: "해당 동작을 직접 확인한 파일과 라인 번호는 어디인가?", "공식 문서의 구체적 근거는 무엇인가?"

### 4. 아키텍처 검증 (Architect Strategist)
- 누수 추상화, 은밀한 결합, 모듈 분리 위반, 미래 기술 부채 누적 가능성을 공격합니다.
- 질문: "이 구조가 단기적 땜빵은 아닌가?", "인터페이스 분리 원칙(ISP)이나 단일 책임 원칙(SRP)을 준수하는가?"

## 사용 절차
1. 계획 요청 시 이 스킬을 활성화하여 4가지 비평 렌즈로 시뮬레이션합니다.
2. 비판 과정을 거쳐 살아남은 유효한 근거와 개선책만 종합합니다.
3. 구체적이고 검증 가능한 단계별 실행 계획(Implementation Plan)으로 정리하여 유저에게 제시합니다.
